# Lab 10: Full Stack Node & Express Lab

## Files Overview

| File | Topic |
|------|-------|
| file1.js | Web Server (http module) |
| file2.js | Client-Server Communication (GET, POST) |
| file3.js | Modules & NPM (fs module) |
| file4.js | Async I/O (Callbacks) |
| file5.js | Non-blocking Code |
| file6.js | JSON Read & Send Data |
| fileexpress.js | Express.js Server |
| fileapi.js | REST API (GET, POST, PUT, DELETE) |

## Setup

```bash
npm install
```

## Run any file

```bash
node file1.js      # Web Server
node file2.js      # GET/POST
node file3.js      # File module
node file4.js      # Async I/O
node file5.js      # Non-blocking
node file6.js      # JSON
node fileexpress.js # Express
node fileapi.js    # REST API
```

## Test REST API

- **GET** → Browser: http://localhost:3000/users
- **POST / PUT / DELETE** → Postman
